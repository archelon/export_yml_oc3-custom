# Экспорт YML для Яндекс.Маркет (OpenCart 3, мульти-фиды)

Кастомный форк модуля для OpenCart 3 от https://opencart3x.ru/. Поддерживает **несколько независимых фидов**, каждый со своими настройками (категории, валюта, статусы, картинки и т.д.) и собственным URL.

Поставляется как `.ocmod` (папка `upload/`, повторяющая корень магазина).

## Требования

- OpenCart / ocStore 3.x (проверялось на 3.0.3.7).
- PHP 7.x+ с расширением `mysqli`.
- Выходной файл — **Windows-1251** (требование Яндекс.Маркета).

## Установка

1. Соберите zip-архив из содержимого `upload/` (внутри архива должна быть папка `upload/`).
2. Админка → **Дополнения → Установка расширений** → загрузите архив.
3. Админка → **Дополнения → Модификаторы** → нажмите «Обновить» (Refresh).
4. Админка → **Дополнения → Каналы продвижения** → найдите «Экспорт YML» → установите (зелёный `+`).

При первой установке создаётся таблица `oc_feed_yandex_market`. Если расширение уже было установлено, а файлы просто перезаписаны поверх, откройте страницу настроек фида — схема инициализируется автоматически (ленивая инициализация), старые настройки `feed_yandex_market_*` будут перенесены в первый фид.

## Использование

- **Дополнения → Каналы продвижения → Экспорт YML** открывает список фидов.
- `+` — создать фид, «карандаш» — редактировать, «копировать» — дублировать выбранные, «корзина» — удалить.
- У каждого фида свой адрес вида:

  ```
  https://ваш-домен/index.php?route=extension/feed/yandex_market&feed_id=1
  ```

  Именно этот адрес указывается в личном кабинете Яндекс.Маркета.
- Если `feed_id` не указан, отдаётся первый активный фид (совместимость со старым одиночным URL).

## Поля фида

| Поле | Назначение |
|------|------------|
| Название | внутреннее имя фида (удобство в списке) |
| Статус | включён / выключен |
| Валюта | валюта цен в фиде |
| Компания, Магазин | данные магазина в `<shop>` |
| Категории | какие категории выгружать |
| Статус в наличии / нет в наличии | сопоставление со статусами товаров |
| Картинки | только главная / все изображения |
| Размеры картинок | 600×600 / оригинал |
| sales_notes | условие продажи |
| Атрибуты / Опции | выгрузка в `offer > param` |
| Описание с HTML-разметкой | оборачивать описание в CDATA |

## Обновление и удаление

- Для обновления просто перезалейте файлы `upload/*`; таблицу удалять не нужно.
- При удалении расширения через админку **данные фидов сохраняются** (таблица не удаляется).

## Структура

```

│   ├── controller/extension/feed/yandex_market.php   # CRUD фидов
│   ├── model/export/yandex_market.php                # схема БД, CRUD, миграция
│   ├── view/template/extension/feed/
│   │   ├── yandex_market_list.twig                   # список фидов
│   │   └── yandex_market.twig                        # форма фида
│   └── language/{ru-ru,en-gb}/extension/feed/yandex_market.php
└── catalog/
    ├── controller/extension/feed/yandex_market.php   # генерация YML
    └── model/export/yandex_market.php                # выборки товаров/категорий
```
